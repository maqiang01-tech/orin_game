# 《异变纪元：幸存者编队》完整策划方案 V6.2

> **版本定位**：五人编队回合制重构完整版  
> **文档性质**：产品总案 + 核心系统案 + 首批内容规格 + 技术落地基线  
> **核心参考方向**：以《最强祖师》式“五人小队、前后排、职业分工、战前搭配、自动/半自动回合战斗”为主要战斗形态，并吸收其他队伍构筑游戏在站位、技能条件、属性弱点、局内构筑和失败学习上的成熟做法。  
> **适配平台**：竖屏移动端，720×1280 基准，Godot 4.7，单机优先，可扩展 Android / iOS / PC。  
> **数值说明**：本文所有倍率、概率、冷却和阈值均为首轮可测试值，不是最终平衡结果；进入制作后必须通过模拟战和实机数据迭代。

## 0. 执行摘要

### 0.1 产品一句话

> 在灵潮摧毁文明后的废土中，玩家扮演能够在死亡后保留记忆的探索者陈末，招募不同职业的伙伴，组建五人编队，通过站位、职业分工、技能连携、属性弱点和异能构式应对战斗；在资源探索与主线推进中承担时间、噪音、负重、伤势和异变风险，并在一次次轮回后改写队伍与世界的命运。

### 0.2 本版本最重要的设计结论

1. **战斗不是战棋**：不做自由走格；采用五人静态阵型、速度排序、自动/半自动/手动可切换的回合制。
2. **策略重心前置**：主要决策发生在战前——选谁、站哪、带什么技能模块、怎样连携、如何针对敌方。
3. **五个基础职业、十个战斗分支**：先锋、游侠、灵能者、斥候、支援者各自拥有两个清晰分支，职业必须有不可替代的机制价值。
4. **站位决定保护和目标关系**：前排不是单纯增加防御，后排也不是绝对安全；护卫、突袭、贯穿、横排、列击、暴露和拦截共同构成位置博弈。
5. **职业克制与属性克制分层**：职业通过机制反制，属性通过弱点与抗性提供软倍率，避免“双重克制直接判死”。
6. **技能组合遵循“铺垫—增幅—终结”**：每支队伍至少围绕一条主连携和一条备用连携构建。
7. **异能依附职业与技能**：异能不是平行于职业的第二套技能栏，而是改变技能目标、代价、状态和终结方式的构式系统。
8. **资源图允许随时撤离**：不强制清敌、清资源后才能离开；贪心与撤退是探索核心。
9. **轮回保留有限选择**：玩家每轮选择记忆、遗产和世界锚点，而不是无限堆永久数值。
10. **首个可玩版本必须真正验证五人队**：至少提供主角加五名伙伴、完整前后排、五种职业功能、一名多阶段 Boss 和一次轮回闭环。

### 0.3 核心体验支柱

| 支柱 | 玩家体验 | 设计约束 |
|---|---|---|
| 五人编队构筑 | 换一名角色、一个站位或一个技能模块，就能改变战术 | 不允许“万能角色”同时承担主坦、治疗、控制和输出 |
| 清晰可读的反制 | 玩家能看懂失败原因，并在下一次调整 | 高威胁技能必须有预警；克制不能只藏在公式里 |
| 探索中的风险取舍 | 玩家决定搜索、绕路、战斗、负重和撤离 | 资源图不强制清图；高收益必须伴随可预见风险 |
| 轮回后的新选择 | 死亡带来情报、保留选择和世界变化 | 避免重复刷完整教学流程；避免只做永久属性树 |
| 异能与代价共存 | 强力能力改变打法，也留下症状与后果 | 异变不能只是高数值收益条，也不能随机无解致死 |

## 1. 产品定位与目标用户

### 1.1 类型定位

- 竖屏单机回合制 RPG。
- 五人编队、战前构筑、自动与半自动战斗。
- 大地图选择目标，小地图进行主线探索或资源探索。
- 伙伴收集和有限养成。
- 轮回推动剧情、世界变化和构筑变化。
- 轻中度操作，适合 5～15 分钟单次游玩，也支持 30～60 分钟完整探索链。

### 1.2 目标用户

| 用户群 | 主要诉求 | 对应设计 |
|---|---|---|
| 回合制阵容玩家 | 配队、克制、养成、自动战斗 | 五职业十分支、前后排、自动策略 |
| 末世生存玩家 | 资源压力、撤离、选择后果 | 时间、噪音、负重、伤势、资源图 |
| Roguelite 玩家 | 每轮不同构筑和失败成长 | 随机资质、异能源核、记忆保留、Boss 情报 |
| 碎片化移动端玩家 | 操作轻、信息明确、可中断 | 竖屏、自动战斗、短节点、战斗暂停与续战 |
| 轻度剧情玩家 | 伙伴关系与世界真相 | 48 章主线、羁绊事件、轮回分支 |

### 1.3 核心卖点

1. **五人阵容不是战力列表，而是可解释的战术系统。**
2. **战斗前看敌方职业、阵型与弱点，再调整自己的位置和连携。**
3. **异能会强化职业打法，同时产生真实的异变症状。**
4. **资源地图允许提前撤离，失败不是“没清完图”，而是判断失误。**
5. **轮回保留情报和有限遗产，Boss 与世界也会对玩家行为作出变化。**

## 2. 核心循环

### 2.1 5～15 分钟短循环

```text
选择探索目标
→ 查看环境、敌方职业和已知弱点
→ 调整五人队伍、站位、技能模块与消耗品
→ 进入 1～3 个探索节点
→ 搜索 / 事件 / 战斗
→ 判断继续深入或撤离
→ 结算资源、伤势、关系和情报
```

### 2.2 30～60 分钟中循环

```text
营地整备
→ 主线任务或资源任务
→ 连续探索与战斗
→ 队伍状态逐渐恶化
→ 精英 / Boss / 关键选择
→ 返回营地
→ 角色成长、装备调整、设施建设、剧情推进
```

### 2.3 单轮循环

```text
随机资质与特质
→ 选择主角战斗专精与异能源核
→ 招募 / 重逢伙伴
→ 推进主线与区域
→ 获取装备、构式、情报和关系
→ 战略撤退 / 队伍覆灭 / 剧情轮回
→ 选择保留记忆、遗产和世界锚点
→ 下一轮世界产生变化
```

### 2.4 系统之间的输入输出

| 系统 | 输入 | 输出到其他系统 |
|---|---|---|
| 探索 | 队伍专长、时间、噪音、负重、道具 | 战斗遭遇、物资、伤势、情报、事件选择 |
| 战斗 | 角色、职业、站位、技能、装备、异能 | 经验、掉落、伤势、污染、Boss 情报 |
| 伙伴 | 招募、好感、创伤、成长分支 | 队伍战术、探索选项、关系事件 |
| 异能 | 源核、构式、污染 | 技能变化、探索捷径、症状、失控危机 |
| 轮回 | 本轮结果、记忆、世界状态 | 下一轮开局、快捷路线、Boss 适应、剧情分支 |

## 3. 主角系统

### 3.1 主角设定

| 项目 | 内容 |
|---|---|
| 姓名 | 陈末 |
| 身份 | 前特种行动人员，灵潮爆发后成为独立探索者 |
| 叙事作用 | 玩家决策载体、轮回记忆持有者、队伍核心 |
| 特殊能力 | 能感知灵潮残留，并在死亡后保留部分记忆 |
| 战斗定位 | 每轮选择一个职业专精，填补队伍缺口 |
| 固定限制 | 主线战斗必须出场；部分支线可派遣伙伴小队 |

### 3.2 六维属性

| 属性 | 战斗作用 | 探索作用 |
|---|---|---|
| 力量 | 物理攻击、破甲效率、近战技能倍率 | 负重、破拆、强行移动障碍 |
| 体质 | 生命、防御、受伤抗性 | 疾病、毒素、疲劳检定 |
| 敏捷 | 速度、闪避、先手修正 | 潜行、追逐、撤离速度 |
| 感知 | 命中、暴击、弱点识别 | 陷阱发现、侦察、物资品质判断 |
| 精神 | 灵能强度、效果抵抗、污染承受 | 灵潮事件、精神检定、异常识别 |
| 魅力 | 增益强度、部分团队技能 | 交涉、招募、关系和交易 |

### 3.3 资质生成

不再采用“低资质与高资质相差数十点、直接决定成败”的强随机方式。推荐：

```text
基础可分配点：24
资质浮动：-2 ～ +4
负面特质补偿：+1 ～ +4
单项初始上限：10
单项最低：2
```

资质主要决定：

- 属性成长上限；
- 某些职业专精的学习成本；
- 特质与事件概率；
- 不直接决定本轮是否值得继续。

### 3.4 属性阈值

属性阈值应解锁“打法权限”，不直接赠送夸张倍率。

| 属性 | 12 点专长 | 20 点专长 | 28 点专长 |
|---|---|---|---|
| 力量 | 重击：破势效率 +10% | 破甲：对护甲目标无视 8% 防御 | 碾压：处决生命低于 20% 的普通敌人 |
| 体质 | 坚韧：重伤概率 -20% | 铁壁：首次受到暴击改为普通伤害 | 不屈：每场首次致命伤保留 1 HP |
| 敏捷 | 抢先：首轮速度 +8 | 残影：闪避后获得 10 能量 | 连贯：每场一次，主动技能后追加普通攻击 |
| 感知 | 鹰眼：远程攻击命中 +10% | 识破：战前显示一个隐藏被动 | 猎杀：对暴露目标暴击伤害 +20% |
| 精神 | 心障：首次精神控制免疫 | 共鸣：异能构式效果 +10% | 稳态：污染达到 75 时仍可正常使用一次技能 |
| 魅力 | 领队：全队士气初始 +5 | 协调：关系技能冷却 -1 | 号令：每场一次使一名队友立即执行普通攻击 |

### 3.5 主角职业专精

每轮开始后，在以下五个职业包中选择一个；选择后本轮锁定，可在轮回后更换。

| 专精 | 推荐主属性 | 主要职责 |
|---|---|---|
| 先锋 | 体质 / 力量 | 前排、保护、破阵 |
| 游侠 | 感知 / 敏捷 | 单体输出、突袭、处决 |
| 灵能者 | 精神 / 感知 | 群体输出、控制、状态引爆 |
| 斥候 | 敏捷 / 感知 | 标记、侦测、干扰、追击 |
| 支援者 | 精神 / 魅力 | 治疗、净化、加速、能量管理 |

主角技能由三个包组合：

```text
职业包：决定普通攻击、基础被动和两个职业技能
武器包：决定攻击类型、射程和一个战术模块
异能源核：修改技能表现、代价与终结方式
```

## 4. 五人编队战斗总则

### 4.1 战斗定位

采用“**战前策略 + 回合制自动战斗**”作为主形态：

| 模式 | 规则 | 使用场景 |
|---|---|---|
| 全自动 | 按玩家预设的技能条件与目标优先级执行 | 日常资源战、重复关卡 |
| 半自动 | 普通攻击与常规技能自动，觉醒技和关键技能可手动 | 默认推荐模式、精英战 |
| 手动 | 玩家逐个选择行动和目标 | Boss、高难挑战、首次教学 |

### 4.2 五人队标准角色结构

推荐基础公式：

```text
主坦 + 副坦/前排功能位 + 主输出 + 副输出/控制 + 支援位
```

该公式是新手理解框架，不是强制模板。可形成单坦双辅助、三前排、双突袭等变体，但任何阵容都必须回答：

- 谁承受第一轮压力；
- 谁负责稳定伤害；
- 谁处理敌方核心机制；
- 谁保证续航或抢节奏；
- 核心角色倒下后是否有备用路径。

### 4.3 胜负条件

| 类型 | 条件 |
|---|---|
| 常规胜利 | 敌方全部战斗单位失去战斗能力 |
| 守护胜利 | 在限定回合内保护目标存活 |
| 生存胜利 | 坚持指定回合或等待撤离完成 |
| 机制胜利 | 破坏核心、关闭装置、阻止仪式 |
| 常规失败 | 我方五名成员均倒地 |
| 特殊失败 | 保护目标死亡、倒计时归零、任务物被摧毁 |

### 4.4 战斗时间目标

| 战斗 | 目标时长 | 目标回合 |
|---|---:|---:|
| 普通战 | 25～60 秒 | 2～5 回合 |
| 精英战 | 60～120 秒 | 5～8 回合 |
| Boss 战 | 3～6 分钟 | 8～15 回合 |
| 高难 Boss | 5～10 分钟 | 12～20 回合 |

## 5. 阵型、站位与目标关系

### 5.1 3×3 阵位容器

战场采用 3×3 数据结构，但每方默认只部署五名角色。首个版本开放以下阵型。

#### 双盾阵：2 前 3 后

```text
敌方方向 ↑

[前左] [ 空 ] [前右]
[ 空 ] [ 空 ] [ 空 ]
[后左] [后中] [后右]
```

- 稳定、教学友好；
- 后中可同时受两个前排保护；
- 害怕横排、贯穿和范围爆发。

#### 锋矢阵：3 前 2 后

```text
[前左] [前中] [前右]
[ 空 ] [ 空 ] [ 空 ]
[后左] [ 空 ] [后右]
```

- 前排攻击 +8%，破势 +10%；
- 后排数量少，核心更容易被锁定；
- 适合快攻、破阵和反击。

#### 鹤翼阵：1 前 2 中 2 后

```text
[ 空 ] [前中] [ 空 ]
[中左] [ 空 ] [中右]
[后左] [ 空 ] [后右]
```

- 中列获得 8% 闪避；
- 前中承担压力极高；
- 适合高练度单坦、双侧翼输出。

#### 分散阵：降低范围伤害

```text
[前左] [ 空 ] [前右]
[ 空 ] [中中] [ 空 ]
[后左] [ 空 ] [后右]
```

- 相邻范围伤害 -15%；
- 群体增益覆盖 -10%；
- 适合对抗爆炸、链式和横排攻击。

MVP 先开放双盾阵，其他阵型在首篇中逐步解锁。

### 5.2 保护关系

双盾阵默认：

```text
前左保护：后左、后中
前右保护：后中、后右
```

规则：

1. 存活前排存在时，近战普通攻击不能直接选择其保护的后排。
2. 远程可以攻击受保护后排，但目标获得“掩护”：受到最终伤害 -8%。
3. 后中同时被两名前排保护时，掩护提升至 -12%，但只触发一次护卫拦截。
4. 对应前排倒地后，后排获得“暴露”：受到单体伤害 +12%，直到阵型恢复或战斗结束。
5. 突袭技能可以跨过前排，但守卫类角色可能拦截。
6. 贯穿技能先命中前排，再对其保护的后排造成 40%～70% 余波伤害。

### 5.3 射程类型

| 射程 | 默认目标 | 站位限制 |
|---|---|---|
| 近战 | 敌方前排 | 后排使用时伤害 -15%，除非技能注明可后排施放 |
| 长柄 | 敌方前排与同列后排 | 后排可正常使用 |
| 远程 | 任意可见目标 | 攻击受保护后排时受掩护影响 |
| 灵能 | 任意目标 | 受精神屏障、沉默和灵能抗性影响 |
| 突袭 | 优先后排 | 可被护卫、警戒和显形反制 |

### 5.4 目标形状

- 单体；
- 横排；
- 同列；
- 相邻；
- 十字；
- 全体；
- 随机 N 次；
- 最低生命；
- 最高攻击；
- 被标记目标；
- 正在蓄力目标；
- 后排优先；
- 召唤物优先。

### 5.5 战中换位

- 不提供免费自由换位。
- 只有技能、击退、拉拽、突袭返回、救援和特定道具可改变阵位。
- 两波战斗之间可免费调整一次阵型。
- 角色被强制移动到不适合的阵位时，部分技能会失效或降低效果，形成可读的反制。

## 6. 回合流程、速度与资源

### 6.1 自然回合流程

```text
回合开始
→ 环境与阶段提示
→ 按速度生成行动队列
→ 每个存活单位行动一次
→ 追击、反击、协同等插入式行动结算
→ 持续伤害、治疗、护盾和冷却结算
→ 回合结束
```

### 6.2 行动顺序

- 按速度从高到低排序。
- 速度相同：玩家方优先；同阵营按“前左、前中、前右、中左、中中、中右、后左、后中、后右”固定顺序。
- 不使用随机先手，确保玩家可预测。
- 行动提前与延后只改变本回合剩余队列或下一回合初始顺位。
- 每名角色每个自然回合最多获得 1 次额外主动行动。
- 额外行动不能再次触发额外行动。

### 6.3 技能资源

推荐将“双轨资源”简化为：

| 资源 | 用途 | 规则 |
|---|---|---|
| 冷却 | 约束常规主动技能 | 技能 1：2～3 回合；技能 2：3～5 回合 |
| 觉醒能量 | 释放觉醒技 | 0～100，普通攻击 +20，主动技能 +10，受击每回合最多 +10 |

常规技能不再同时消耗能量和冷却，避免管理负担。少数特殊角色可以把能量当核心机制。

### 6.4 基础行动

| 行动 | 效果 |
|---|---|
| 普通攻击 | 无冷却，获得 20 能量 |
| 技能一 | 主要循环技能，短冷却 |
| 技能二 | 强力功能技能，中长冷却 |
| 觉醒技 | 消耗 100 能量，改变局势 |
| 防御 | 本次行动不攻击；至下次行动前最终减伤 30%，获得 25 能量 |
| 道具 | 消耗队伍道具次数；每自然回合全队最多使用 1 件战斗道具 |

### 6.5 插入式行动上限

为防止无限追击：

- 每角色每回合最多反击 2 次；
- 每角色每回合最多协同攻击 2 次；
- 同一次攻击链最多追加 4 次插入行动；
- 追击、反击和协同攻击默认不获得觉醒能量；
- 被动造成的额外伤害不能再次触发相同被动。

## 7. 职业系统：五职业十战斗分支

### 7.1 职业设计原则

1. 职业决定角色在队伍中“做什么”。
2. 角色技能决定该角色“怎样做”。
3. 异能构式决定技能“以什么代价和方式变化”。
4. 装备只强化和偏转，不得把一个职业完整替换成另一个职业。
5. 每个职业都必须有独占价值、明确弱点和至少一种反制方式。

### 7.2 五个基础职业

| 职业 | 基础定位 | 核心职责 | 常见站位 |
|---|---|---|---|
| 先锋 | 坦克 / 前排输出 | 承压、护卫、破甲、反击 | 前排 |
| 游侠 | 物理主输出 | 精准单点、突袭、处决 | 后排 / 侧翼 |
| 灵能者 | 灵能输出 / 控制 | 群攻、控制、状态引爆 | 后排中央 |
| 斥候 | 标记 / 干扰 | 侦测、追击、削能、封技 | 后排侧翼 |
| 支援者 | 治疗 / 节奏 | 治疗、净化、护盾、加速 | 后排中央 |

### 7.3 十个分支总表

| 分支 | 推荐位置 | 核心机制 | 队伍价值 | 主要弱点 |
|---|---|---|---|---|
| 守卫先锋 | 前排 | 护卫、拦截、分摊 | 保住核心后排 | 破甲、腐蚀、禁护卫 |
| 破阵先锋 | 前排 | 破势、反击、削甲 | 拆坦、提供终结窗口 | 控制、缴械、远程风筝 |
| 狙击游侠 | 后排 | 标记、蓄力、处决 | 单体主 C | 突袭、复活、目标转移 |
| 突袭游侠 | 后排侧翼 | 越前排、击杀刷新 | 切后排、快攻 | 守卫、警戒、反击 |
| 轰击灵能者 | 后排中 | 范围、叠层、引爆 | 群体主 C | 沉默、分散阵、高灵抗 |
| 心控灵能者 | 后排 | 沉默、恐惧、延后 | 控制核心、抢节奏 | 净化、效果抵抗、免控 |
| 追猎斥候 | 后排侧翼 | 标记、显形、协同 | 放大单体连携 | 驱散标记、嘲讽、范围压制 |
| 干扰斥候 | 后排 | 削能、封技、拆增益 | 克制觉醒与技能循环 | 普攻队、被动队、高速突袭 |
| 医疗支援 | 后排中 | 治疗、净化、复苏 | 长线续航 | 禁疗、爆发、处决 |
| 战术支援 | 后排 | 加速、护盾、能量 | 让阵容按计划启动 | 驱散、沉默、切后排 |

### 7.4 分支详细规则

#### 7.4.1 守卫先锋

**职业被动：护卫阵线**

- 每回合首次有相邻受保护后排被突袭时，自动拦截。
- 拦截伤害降低 20%。
- 每次成功拦截获得 1 层“坚守”，最多 3 层。
- 3 层坚守时，下一次主动技能为全队提供 6% 自身最大生命的护盾。

**职业权限**：唯一稳定拥有“替伤”和“多目标护卫”的分支。  
**禁止越界**：输出倍率不能接近主 C；不能同时拥有强治疗和高频硬控。

#### 7.4.2 破阵先锋

**职业被动：越战越勇**

- 受到直接攻击或命中敌方前排时获得 1 层战意，最多 4 层。
- 每层战意：攻击 +3%、效果抵抗 +3%。
- 满层后下一次主动技能额外施加“破甲 15%”与“破势 +30%”。

**职业权限**：稳定破甲、破势、前排压制。  
**禁止越界**：不能获得守卫先锋同等级的全队保护。

#### 7.4.3 狙击游侠

**职业被动：锁定弱点**

- 攻击“标记”或“暴露”目标时命中 +15%。
- 对生命低于 35% 的目标伤害 +20%。
- 击败目标恢复 25 能量；每回合最多一次。

**职业权限**：最高单体终结能力。  
**禁止越界**：群体输出必须明显弱于轰击灵能者。

#### 7.4.4 突袭游侠

**职业被动：侧翼渗透**

- 每场首次突袭可无视前排保护。
- 攻击后排后获得“闪身”：下一次受到单体攻击时闪避 +20%。
- 若突袭被拦截，则不获得闪身。

**职业权限**：主动改变后排安全关系。  
**禁止越界**：正面持续输出低于狙击；面对守卫必须有明显代价。

#### 7.4.5 轰击灵能者

**职业被动：灵能共振**

- 敌人每携带一种可引爆异常，范围技能伤害 +5%，最多 +20%。
- 每回合第一次引爆异常时，恢复 10 能量。

**职业权限**：范围状态引爆。  
**禁止越界**：不能同时具备高额单体处决和稳定治疗。

#### 7.4.6 心控灵能者

**职业被动：精神压迫**

- 对尚未行动的目标施加控制时，效果命中 +12%。
- 每次控制成功获得 1 层心印，最多 3 层。
- 3 层心印使下一次控制技能冷却 -1，并清空心印。

**职业权限**：硬控、软控、行动顺序干预。  
**禁止越界**：Boss 不能被无限硬控；控制链必须存在递增抗性。

#### 7.4.7 追猎斥候

**职业被动：协同猎杀**

- 标记目标后，队友首次攻击该目标时，追猎者追加一次 40% 普通攻击的协同射击。
- 每回合最多协同两次。
- 标记同时降低目标 10% 闪避。

**职业权限**：标记与协同攻击。  
**禁止越界**：不应同时成为最高爆发主 C。

#### 7.4.8 干扰斥候

**职业被动：信号阻断**

- 普通攻击额外削减目标 8 点觉醒能量。
- 对机械或护盾目标，削能提高至 12 点。
- Boss 免疫“技能永久封锁”，但封技可转化为技能冷却 +1 或蓄力延长。

**职业权限**：能量、冷却与增益控制。  
**禁止越界**：不能拥有大范围稳定硬控和高输出。

#### 7.4.9 医疗支援

**职业被动：紧急救护**

- 每回合首次有队友生命低于 30% 时，自动治疗其 8% 最大生命。
- 每场最多触发 3 次。
- 复苏类效果每场战斗全队最多成功一次。

**职业权限**：稳定治疗、净化、复苏。  
**禁止越界**：其他职业只能拥有小额自疗或条件恢复，不能替代医疗位。

#### 7.4.10 战术支援

**职业被动：战术网络**

- 战斗开始时，使速度最高的两名队友首回合速度 +8。
- 每当自身施加增益，目标获得 5 点能量；每目标每回合一次。

**职业权限**：抢先手、能量、护盾、冷却管理。  
**禁止越界**：不能同时提供顶级治疗、顶级控制和高输出。

## 8. 职业克制与软反制矩阵

职业克制不采用固定“职业 A 对职业 B 伤害 +30%”。其优势由机制产生。

| 进攻/功能方 | 主要克制对象 | 机制原因 | 被反制方式 |
|---|---|---|---|
| 守卫先锋 | 突袭游侠 | 拦截、护卫、目标转移 | 破甲、禁护卫、范围伤害 |
| 破阵先锋 | 守卫先锋、护盾队 | 破甲、破势、反击 | 沉默、缴械、远程控制 |
| 狙击游侠 | 单核、残血、暴露目标 | 标记处决、精准单点 | 复苏、转移目标、突袭 |
| 突袭游侠 | 医疗、控制、战术支援 | 越前排、后排爆发 | 护卫、警戒、反击 |
| 轰击灵能者 | 召唤、多目标、密集阵 | 范围与状态引爆 | 分散阵、灵抗、沉默 |
| 心控灵能者 | 慢速破阵、蓄力输出 | 沉默、延后、恐惧 | 净化、免控、高速先手 |
| 追猎斥候 | 闪避、隐匿、单体 Boss | 显形、标记、协同 | 驱散、嘲讽、范围压制 |
| 干扰斥候 | 觉醒依赖、护盾机械队 | 削能、封技、拆增益 | 普攻强化、被动输出、净化 |
| 医疗支援 | 持续伤害、消耗阵容 | 治疗、净化、复苏 | 禁疗、处决、爆发 |
| 战术支援 | 慢速队、技能循环队 | 加速、能量、冷却 | 驱散、沉默、切后排 |

设计要求：任何职业优势都必须能通过敌方阵容、站位、装备或战术模块部分弥补，禁止形成“未持有特定职业就无法通过”的绝对门槛。

## 9. 战斗属性、弱点与抗性

### 9.1 五种攻击属性

| 属性 | 核心异常 | 典型克制 | 典型抗性 |
|---|---|---|---|
| 动能 | 失衡、破势、击退 | 轻装、脆弱结构、蓄力单位 | 重甲、固定型核心 |
| 热能 | 灼烧、禁疗、熔解 | 再生、生体组织、虫群 | 耐热、无机核心 |
| 电磁 | 过载、削能、护盾破坏 | 机械、无人机、能量盾 | 绝缘、生物型目标 |
| 腐蚀 | 腐蚀、降甲、坏死 | 重甲、甲壳、高治疗 | 相位体、封闭防护 |
| 灵能 | 恐惧、混乱、精神穿透 | 低意志、灵体、裂隙目标 | 无心智、精神屏障 |

### 9.2 敌人防御标签

每个敌人至少拥有：

```text
1 个主体标签：生体 / 机械 / 灵体 / 混合
1 个装甲标签：轻装 / 重甲 / 护盾 / 无甲
1 个弱点属性
1 个抗性属性
0～2 个机制标签：再生 / 飞行 / 隐匿 / 固定 / 召唤 / 蓄力
```

### 9.3 属性倍率

```text
命中弱点：最终伤害 ×1.25，相关异常基础命中 +15%
命中抗性：最终伤害 ×0.80，相关异常基础命中 -20%
普通关系：最终伤害 ×1.00
```

- Boss 弱点不等于全程常驻；可通过破部位、情报或状态创造“弱点窗口”。
- 属性增伤与职业机制叠加后，单次最终乘区总上限建议为 ×1.65。
- 不设置五属性循环，以避免末世题材中生硬的“火克木”关系。

### 9.4 破势系统

每个敌人拥有“稳定值”。

- 命中弱点：破势 +25%；
- 使用破阵、击退、打断技能：按技能增加破势；
- 稳定值归零：目标进入“失衡”1 回合；
- 失衡：无法护卫，防御 -15%，下次行动延后至队列末尾；
- Boss 失衡持续到其下一次行动前，并获得 2 回合破势抗性，防止无限循环。

## 10. 战斗属性与公式

### 10.1 核心属性

| 属性 | 用途 |
|---|---|
| HP | 生命上限 |
| ATK | 物理、动能、热能与部分腐蚀技能基础值 |
| PSY | 灵能、治疗、护盾与部分异常技能基础值 |
| DEF | 物理与一般能量伤害减免 |
| RES | 灵能伤害与异常抵抗 |
| SPD | 行动顺序 |
| ACC | 命中 |
| EVA | 闪避 |
| EFF | 效果命中 |
| TEN | 效果抵抗 |
| CRIT | 暴击率 |
| CRIT_DMG | 暴击伤害 |
| HEAL | 治疗增益 |

### 10.2 伤害公式

物理/一般伤害：

```text
基础伤害 = 攻击属性 × 技能倍率 + 固定值
防御系数 = K / (K + 有效防御)
最终伤害 = 基础伤害
         × 防御系数
         × 属性关系
         × 位置修正
         × 增伤乘区
         × 暴击乘区
         × 0.95～1.05 随机浮动
```

灵能伤害将 ATK 替换为 PSY，将 DEF 替换为 RES。

首测建议：

```text
K = 100 + 攻击者等级 × 12
最终减伤上限 = 75%
最终增伤乘区上限 = 165%
随机浮动 = ±5%
```

### 10.3 暴击

```text
最终暴击率 = 5% + 感知 ×0.35% + 装备与技能修正
暴击率上限 = 75%
基础暴击伤害 = 150%
暴击伤害上限 = 250%
```

持续伤害默认不能暴击，除非技能或构式明确允许。

### 10.4 命中与闪避

```text
最终命中率 = clamp(95% + ACC - EVA, 60%, 100%)
```

- 硬控技能未命中时不施加状态；
- 无法通过堆闪避达到近乎无敌；
- Boss 关键技能最低命中 80%，但必须有可见反制。

### 10.5 状态命中

```text
状态成功率 = clamp(基础概率 × (1 + EFF - TEN), 15%, 95%)
```

EFF、TEN 使用小数比例，例如 0.20 表示 20%。

Boss 控制递减：

- 首次硬控：正常；
- 2 回合内第二次同类硬控：持续时间 -1 或成功率 ×0.5；
- 第三次：转化为行动延后 15%，不再完全失去行动。

### 10.6 治疗与护盾

```text
治疗量 = PSY × 技能倍率 × (1 + HEAL) × 目标受疗修正
护盾量 = PSY 或最大生命 × 技能倍率
```

- 单个护盾不叠加，同来源取高值并刷新持续时间；
- 不同类型护盾可叠加，但总护盾不超过目标最大生命 60%；
- 过量治疗默认浪费，特定构式可转化为护盾或再生。

## 11. 状态效果字典

### 11.1 控制类

| 状态 | 效果 | 默认持续 | 说明 |
|---|---|---:|---|
| 眩晕 | 跳过下一次主动行动 | 1 次行动 | 强控，Boss 受递减 |
| 沉默 | 不能使用主动技能与觉醒技 | 1 回合 | 可普通攻击和防御 |
| 缴械 | 不能进行物理攻击类技能 | 1 回合 | 灵能技能不受影响 |
| 恐惧 | 行动时有 50% 改为防御，并失去目标锁定 | 1 回合 | Boss 转为伤害降低 |
| 嘲讽 | 单体技能优先攻击施加者 | 1～2 回合 | 范围技能不受限制 |
| 禁疗 | 受到治疗降低 50% | 2 回合 | 可被净化 |
| 定身 | 不能换位、突袭或被友方交换位置 | 1 回合 | 不影响普通行动 |

### 11.2 伤害与破坏类

| 状态 | 效果 |
|---|---|
| 灼烧 | 回合末造成热能持续伤害；降低 15% 受疗 |
| 腐蚀 | 每层降低 4% DEF，最多 5 层；回合末小额伤害 |
| 过载 | 能量获取 -30%；叠至 3 层时护盾破裂并失衡 |
| 流血 | 主动攻击后受到伤害；防御行动不触发 |
| 坏死 | 最大生命暂时降低，战斗结束后恢复；普通敌人最低降至 70% |

### 11.3 战术类

| 状态 | 效果 |
|---|---|
| 标记 | 可被狙击、协同和处决类技能识别 |
| 暴露 | 失去掩护，单体伤害 +12% |
| 警戒 | 下一次敌方突袭时发动拦截或反击 |
| 护卫 | 指定角色替目标承担攻击 |
| 破甲 | 按百分比降低有效防御 |
| 加速 / 减速 | 修改本回合或下回合行动顺序 |
| 免疫 | 阻挡下一次可驱散负面状态，不阻挡伤害 |
| 再生 | 回合末恢复生命，可被热能和禁疗压制 |

### 11.4 净化层级

- 弱负面：减攻、减防、减速、标记；
- 中负面：灼烧、腐蚀、过载、禁疗；
- 强负面：眩晕、沉默、恐惧、坏死；
- 普通净化优先移除弱或中负面；
- 强净化可指定移除强负面，冷却更长；
- Boss 专属状态通常不可直接净化，只能通过机制解除。

## 12. 技能系统与构筑结构

### 12.1 每名角色的战斗组件

```text
普通攻击：固定
职业被动：固定
角色核心被动：固定
技能一：固定主体，拥有模块分支
技能二：固定主体，拥有模块分支
觉醒技：固定主体，拥有一条强化路径
战术模块：三选一
异能构式：符合条件的角色可选一至两个
```

战斗界面只显示：普通攻击、技能一、技能二、觉醒技，避免按钮膨胀。

### 12.2 技能标签

| 标签 | 作用 |
|---|---|
| 起手 | 提供标记、破甲、增益或控制 |
| 增幅 | 扩大前置状态收益 |
| 终结 | 消耗状态、处决或引爆 |
| 保护 | 护卫、护盾、减伤、转移目标 |
| 打断 | 取消蓄力或延长 Boss 技能 |
| 净化 | 移除负面、抵抗控制 |
| 回复 | 治疗、吸血、复苏 |
| 追击 | 队友行动后插入攻击 |
| 反击 | 受到攻击后插入攻击 |
| 位移 | 改变阵位或暴露目标 |

### 12.3 模块规则

- 每个技能首版只提供 2～3 个模块；
- 模块必须改变使用方式，不只增加 10% 数值；
- 同一技能同时只能启用一个模块；
- 营地可免费更换，探索途中只能在安全节点更换；
- 自动 AI 会读取模块效果和使用条件。

### 12.4 模块示例：狙击技能“贯穿狙杀”

| 模块 | 改变 |
|---|---|
| 穿线弹 | 目标被击败时，剩余伤害的 60% 传递给同列后方单位 |
| 延迟弹 | 未击败时，使目标下一回合速度 -20，并延长蓄力 1 回合 |
| 处刑弹 | 对生命低于 35% 的目标倍率提高，但冷却 +1 |

### 12.5 自动战术配置

每名角色可配置：

**技能优先级**

```text
技能二 → 技能一 → 普通攻击
```

**目标优先级**

- 最低生命；
- 最高攻击；
- 后排；
- 被标记；
- 暴露；
- 正在蓄力；
- 护盾最高；
- 默认前排。

**条件示例**

- 敌人数 ≥3 时使用群攻；
- 队友生命 <40% 时治疗；
- 存在可净化强负面时使用净化；
- 目标有 3 层腐蚀时使用终结；
- Boss 蓄力时优先打断；
- 觉醒技：满能即放 / Boss 阶段 / 手动保留。

自动模式必须使用玩家配置，不得获得隐藏数值补偿。

## 13. 技能连携与阵容流派

### 13.1 连携结构

每支成熟队伍至少包含：

```text
主连携：稳定循环，负责主要胜利路径
备用连携：主连携被反制后仍能工作
生存闭环：护卫 / 治疗 / 控制 / 快攻中至少一项
```

### 13.2 标记处决流

```text
追猎斥候施加标记
→ 破阵先锋削甲并制造暴露
→ 狙击游侠终结
```

- 强项：Boss、精英、单核后排；
- 弱项：召唤物、复苏、目标转移；
- 关键属性：感知、命中、暴击、破甲；
- 备用路径：追猎协同攻击处理小怪。

### 13.3 电磁过载流

```text
干扰斥候施加过载
→ 战术支援加速与供能
→ 轰击灵能者引爆过载
```

- 强项：机械、护盾、依赖觉醒技的敌人；
- 弱项：绝缘生体、高灵抗；
- 终结效果：护盾破裂、能量清空、群体失衡。

### 13.4 护卫反击流

```text
守卫先锋建立护卫
→ 敌方突袭被拦截
→ 破阵先锋 / 反击角色追加攻击
→ 医疗支援维持前排
```

- 强项：快攻、突袭、多段单体；
- 弱项：腐蚀、禁疗、无视护卫的范围攻击；
- 核心风险：过度依赖前排，前排被拆后迅速崩盘。

### 13.5 心智压制流

```text
战术支援抢先
→ 心控灵能者沉默或延后核心敌人
→ 干扰斥候削能
→ 主 C 在安全窗口输出
```

- 强项：技能依赖型敌人、蓄力 Boss；
- 弱项：高抵抗、免控、被动反击队。

### 13.6 腐蚀坏死流

```text
腐蚀技能叠层
→ 破阵先锋降低护甲
→ 热能或灵能终结将腐蚀转为坏死
```

- 强项：重甲、高回复；
- 弱项：短战、频繁净化、相位体。

### 13.7 灼烧再生压制流

```text
热能角色施加灼烧
→ 群体扩散
→ 医疗或灵能角色将过量灼烧转为爆发
```

- 强项：再生、虫群、长线 Boss；
- 弱项：耐热、快速净化、爆发快攻。

## 14. 典型五人阵容

### 14.1 新手标准队

```text
前排：陈锋（守卫） + 陈末（破阵）
后排：苏晓（狙击） + 林美（心控） + 小七（医疗）
```

- 完整包含保护、破甲、单体输出、控制、治疗；
- 教学最清晰；
- 群体清怪速度一般。

### 14.2 标记狙杀队

```text
前排：陈锋（守卫） + 陈末（破阵）
后排：老周（追猎） + 苏晓（狙击） + 小七（医疗）
```

行动逻辑：标记 → 削甲 → 狙杀。  
适合：精英、Boss、单核敌人。  
害怕：高召唤、多复苏、群体压力。

### 14.3 灵能爆发队

```text
前排：陈锋（守卫） + 江离（破阵）
后排：沈琳（轰击） + 林美（心控） + 战术支援角色
```

行动逻辑：先手控制 → 状态铺设 → 范围引爆。  
适合：群怪、召唤、密集阵。  
害怕：沉默、分散阵、高灵能抗性。

### 14.4 铁壁反击队

```text
前排：陈锋（守卫） + 江离（反击破阵）
后排：苏晓（狙击） + 小七（医疗） + 战术支援角色
```

- 通过护卫、反击和恢复消耗敌人；
- 主 C 安全，容错高；
- 害怕腐蚀、禁疗和百分比生命伤害。

### 14.5 双突袭快攻队

```text
前排：陈末（破阵） + 高生存突袭角色
后排：江离（突袭） + 老周（干扰） + 战术支援角色
```

- 第一回合切掉治疗或控制；
- 若未能造成减员，后续续航不足；
- 被守卫和警戒强烈克制。

### 14.6 单坦双辅助队

```text
前排：陈锋（守卫）
中/后排：主 C + 副 C + 医疗支援 + 战术支援
```

- 适合高练度主坦和固定 Boss；
- 输出循环稳定；
- 主坦被破甲或控制后容易整体崩溃。

### 14.7 三前排压制队

```text
前排：守卫先锋 + 破阵先锋 + 近战突袭
后排：主 C + 医疗/战术支援
```

- 强化前排压力和破势；
- 后排更容易被锁定；
- 适合短战和锋矢阵。

### 14.8 无治疗极限队

```text
前排：守卫 + 破阵
后排：主 C + 副 C + 战术支援
```

- 用护盾、控制和快攻替代治疗；
- 资源探索中伤势累积快；
- 适合作为高风险高收益构筑，而非通用答案。

|---|---|---|
| 本轮等级 | 是 | 基础属性与技能等级，等级上限 30 |
| 本轮装备 | 是 / 部分遗产可保留 | 武器、防具、饰品、消耗品 |
| 记忆阶级 | 否 | 解锁模块、角色故事、初始技能等级 |
| 羁绊关系 | 部分保留 | 联携技能、剧情、事件选项 |

### 16.2 角色成长分支

每名伙伴在记忆阶级 3 时选择一个本轮分支：

- 角色 A 路径强化其主职责；
- 角色 B 路径增加副职责，但不超过纯职业角色；
- 每轮可重选，形成轮回构筑差异。

### 16.3 关系技能

关系技能必须改变动作，不能只有全属性 +5%。

| 组合 | 关系技能 | 效果 |
|---|---|---|
| 林美 × 陈锋 | 守住呼吸 | 陈锋为林美拦截后，林美立即为其移除一个弱负面 |
| 苏晓 × 老周 | 交叉观察 | 老周标记目标后，苏晓首次攻击无视掩护 |
| 小七 × 陈锋 | 生命线 | 陈锋低于 25% 生命时，小七紧急救护不消耗本回合触发次数一次 |
| 沈琳 × 林美 | 情绪燃点 | 被林美控制的目标受到灼烧时，灼烧层数 +1 |
| 江离 × 苏晓 | 双线处决 | 江离使后排暴露后，苏晓对其下一次攻击冷却 -1 |

每场最多装备 2 组关系技能，防止被动过多。

### 16.4 创伤与伤势

- 普通战倒地：获得轻伤概率；
- 精英/Boss 倒地：获得中伤或心理创伤概率；
- 重伤影响后续探索与战斗，回营地治疗；
- 伤势具有明确恢复方式，不做永久随机废角；
- 某些伤痕可在轮回后转化为正负两面的永久特质。

## 17. 异能系统：源核、构式与异变

### 17.1 系统定位

```text
职业：决定角色职责
角色技能：决定具体打法
异能源核：决定本轮超自然规则
构式：改变现有技能
异变症状：为强力构筑提供代价
```

主角每轮必选一个源核；部分伙伴拥有固定异能天赋，但不自由装备完整源核。

### 17.2 六大源核

| 源核 | 战斗动词 | 适配职业 | 探索用途 | 典型代价 |
|---|---|---|---|---|
| 动能 | 推、拉、破势、撞击 | 先锋、狙击 | 破门、搬运、清障 | 反冲、骨伤 |
| 生体 | 再生、寄生、抽取 | 医疗、守卫 | 判断生命、应急治疗 | 饥饿、组织增殖 |
| 心智 | 预判、链接、恐惧 | 心控、战术支援 | 读记忆、交涉 | 幻听、伪信息 |
| 时序 | 提前、延后、重复 | 狙击、干扰、支援 | 预览事件结果 | 时债、行动延迟 |
| 构造 | 护盾、陷阱、锚定 | 守卫、支援、斥候 | 修复、破解、电力 | 过载、移动受限 |
| 裂隙 | 瞬移、换位、放逐 | 突袭、追猎 | 穿过封锁、捷径 | 失真、污染增长 |

### 17.3 槽位

| 槽位 | 数量 |
|---|---:|
| 源核 | 1 |
| 主构式 | 1 |
| 次构式 | 1 |
| 反应构式 | 1 |
| 失控技 | 污染达到 75 后临时开放 |

### 17.4 构式示例

**时序构式：迟来的子弹**  
苏晓的贯穿狙杀未击败目标时，在回合末重复造成原伤害 35%，但苏晓下一回合速度 -12。

**动能构式：护卫反冲**  
陈锋拦截突袭后，对攻击者造成 50% ATK 反击并破势 15；每回合一次。

**生体构式：过量生长**  
小七过量治疗的 50% 转化为再生，目标污染 +3。

### 17.5 异能共鸣

| 前置状态 | 后续动作 | 共鸣结果 |
|---|---|---|
| 失衡 | 动能终结 | 坍塌：取消蓄力、相邻暴露 |
| 标记 | 时序延迟弹 | 预演：下一名攻击者必定命中 |
| 腐蚀 3 层 | 热能攻击 | 坏死：降低受疗与最大生命 |
| 护盾 | 构造过载 | 反射屏障：破盾时对攻击者造成伤害 |
| 恐惧 | 突袭 | 溃逃：目标无法被护卫 |
| 寄生 | 群体治疗 | 增殖：过量治疗转为临时护甲 |

### 17.6 污染与症状

污染 0～100：

| 阈值 | 事件 |
|---:|---|
| 25 | 从 3 个轻度症状中选 1 个 |
| 50 | 症状进化或获得第二症状 |
| 75 | 解锁失控技，同时获得重度代价 |
| 100 | 进入失控危机，不立即判定结束 |

症状示例：

| 症状 | 收益 | 代价 |
|---|---|---|
| 相位皮肤 | 首次远程单体攻击必定闪避 | 直接治疗 -30% |
| 回声耳 | 额外显示一项敌方技能提示 | 可能出现可识别的伪提示 |
| 骨质增殖 | 被近战命中时反伤 | 速度 -8，换位类效果成本提高 |
| 饥饿组织 | 击杀后恢复生命 | 食物消耗 +25% |
| 时间裂纹 | 每场首次技能重复 40% 效果 | 下一回合速度 -20 |
| 空洞器官 | 可超负重携带一件物品 | 撤离失败时该物必失 |

### 17.7 失控危机

污染达到 100：

```text
触发一次强制失控技
→ 提供救援窗口
→ 抑制剂 / 伙伴安抚 / 牺牲遗物 / 紧急撤离
→ 处理失败后进入异化结局或特殊支线
```

## 19. Boss 系统

### 19.1 Boss 设计模板

每个 Boss 必须包含：

1. 教学或检验目标；
2. 阵型与部位；
3. 固定行动循环；
4. 至少一个可打断技能；
5. 至少一个站位问题；
6. 两到三个阶段变化；
7. 失败后可解锁的情报；
8. 不同阵容的替代解法；
9. 轮回后的轻度适应；
10. 明确的视觉与音效预警。

### 19.2 首篇 Boss：缝合感染体

**设计目标**：教学护卫、横排伤害、蓄力打断、尸体管理、部位破坏和 Boss 情报。

#### 战场

```text
前排：拖行肢 / 主体 / 拖行肢
后排：缝囊 / 尸堆 / 缝囊
```

#### 行动循环

| 回合 | 行动 | 预警 | 反制 |
|---:|---|---|---|
| 1 | 拖行横扫：攻击前排横排并拉向中心 | 地面红线、拖行肢抬起 | 分散、护盾、破坏拖行肢 |
| 2 | 缝合：吸收尸堆恢复并召唤感染者 | 缝囊与尸堆连线 | 点燃尸堆、打断、优先击破缝囊 |
| 3 | 痉挛冲撞：攻击中心列 | 中心列闪烁 | 调整阵型、守卫拦截、使其失衡 |
| 4 | 污血喷发：全体灼烧/腐蚀二选一 | 身体颜色变化 | 净化、属性抗性、速杀部位 |

#### 阶段

- 生命 70%：缝囊暴露，部位可选中；
- 生命 40%：根据先破坏部位改变形态；
  - 先毁拖行肢：失去拉拽，获得后排跳扑；
  - 先毁缝囊：失去治疗，横扫频率提高；
- 生命 15%：“拒绝死亡”，三处缝线出现；两回合内破坏，否则恢复至 30%。

#### 情报

| 遭遇结果 | 永久情报 |
|---|---|
| 首次见到缝合 | 缝合技能目标是尸堆 |
| 首次被横扫击败 | 显示完整横扫范围 |
| 首次进入第二阶段 | 显示部位破坏会改变形态 |
| 击败 | 解锁完整循环和隐藏采样点 |

#### 轮回适应

若上一轮玩家大量依赖护盾：Boss 的首次横扫带“撕盾”，但该动作蓄力延长，允许打断。适应只增加应对环节，不使护盾流完全失效。

### 19.3 后续 Boss 主题

| Boss | 检验主题 |
|---|---|
| 极光实验体·力 | 守卫与破势、反击窗口 |
| 母巢核心 | 召唤管理、热能禁疗、群攻 |
| 极光·盾 | 腐蚀、破甲、属性弱点窗口 |
| 极光·灵 | 精神控制、净化与效果抵抗 |
| 极光·速 | 命中、标记、先手和突袭 |
| 极光聚合体 | 多职业切换、备用连携 |
| 虚空吞噬者 | 站位变化、裂隙与撤离选择 |
| 灵潮之核 | 复制玩家构筑、轮回情报总检验 |

## 20. 探索系统

### 20.1 两层地图

```text
世界大地图：选择区域、主线、资源点、营地、九域入口
↓
小地图：具体场景、房间、敌人、搜索点、出口和事件
```

### 20.2 主线地图与资源地图分工

| 地图 | 结构 | 主要目标 | 出口规则 |
|---|---|---|---|
| 主线地图 | 手工设计 8～15 节点 | 剧情、机制教学、关键战斗 | 出口可见，但受任务条件限制 |
| 资源地图 | 模块化随机 6～10 房间 | 收集物资并控制风险 | 发现撤离点后可随时离开 |

### 20.3 资源地图核心压力

| 压力 | 来源 | 后果 |
|---|---|---|
| 时间 | 移动、搜索、治疗、休息 | 昼夜变化、事件错过、敌人强化 |
| 噪音 | 强拆、枪械、警报、战斗 | 巡逻、增援、猎杀者进入 |
| 负重 | 物资和装备 | 移动变慢、撤离风险、无法携带更多 |
| 伤势 | 战斗倒地、陷阱、疾病 | 战斗属性下降、需要治疗 |
| 污染 | 异能、裂隙、事件 | 症状、失控危机 |

### 20.4 搜索点选择

示例：药房锁柜。

| 方式 | 时间 | 噪音 | 收益/风险 |
|---|---:|---:|---|
| 快速翻找 | 10 分钟 | +15 | 获得 40%～70% 物资，可能漏掉稀有物 |
| 仔细搜索 | 30 分钟 | +5 | 获得 80%～100% 物资 |
| 强行撬锁 | 5 分钟 | +30 | 必得锁柜物资，可能触发战斗 |
| 斥候侦察 | 15 分钟 | 0 | 先显示陷阱与品质，再决定 |
| 构造异能 | 0 | 污染 +10 | 无声打开，消耗构式资源 |

### 20.5 噪音轨道

| 噪音 | 后果 |
|---:|---|
| 0～29 | 正常 |
| 30 | 巡逻敌人移动 |
| 60 | 精英出现或通路封锁 |
| 90 | 猎杀者进入并追踪玩家 |
| 100 | 地图警戒，撤离路线变化 |

后果必须提前显示在轨道上，避免后台随机惩罚。

### 20.6 敌情预览与编队调整

- 发现敌人后显示：阵型、职业图标、已知属性、弱点、Boss 情报；
- 未被发现时可能进入伏击，敌方首回合速度提升；
- 战斗前允许调整阵型、技能模块和一件道具；
- 同一探索中换人只能在安全房间或营地节点完成；
- 斥候职业可以提高敌情预览完整度。

### 20.7 撤离

- 资源地图：发现出口后可随时撤离；
- 主线地图：完成最低任务条件后可正常撤离；
- 紧急撤离：任何地图可尝试，需 2 回合战斗或一次检定；失败会丢失未固定物资；
- 负重越高，撤离时间越长；
- 伤势和追兵会改变撤离战斗。

## 22. 轮回系统

### 22.1 核心理念

> 轮回不是清空存档，而是让玩家用有限记忆重新选择队伍、职业、异能和世界路径。

### 22.2 本轮失去与保留

| 本轮结束后失去 | 永久保留 / 可选择保留 |
|---|---|
| 本轮等级 | 已解锁伙伴 |
| 大部分本轮装备 | 图鉴和基础配方 |
| 普通资源 | Boss 情报 |
| 大部分地图临时状态 | 剧情记忆 |
| 本轮职业专精 | 记忆阶级与羁绊基础 |
| 临时异能构式 | 选择的一件遗产构式 |

### 22.3 三类保留选择

| 类型 | 每轮数量 | 示例 |
|---|---:|---|
| 记忆 | 2～3 | Boss 弱点、地图捷径、事件密码、配方 |
| 遗产 | 1 | 起始装备、构式、伙伴模块、蓝图 |
| 世界锚点 | 1 | 让 NPC、设施、通道或区域状态延续 |

### 22.4 主动轮回

只能在营地或安全屋执行：

- 保留更多本轮资源；
- 可指定一项额外记忆；
- 放弃尚未完成的突破奖励；
- 世界威胁推进一次；
- 适合在队伍伤势严重、构筑失衡或关键资源不足时战略撤退。

### 22.5 避免重复章节

已完成且没有新变化的章节可选择：

- 快速结算；
- 只处理关键事件；
- 从世界锚点开始；
- 消耗资源直接抵达已知节点；
- 新轮回出现的变化节点仍需实际游玩。

### 22.6 Boss 适应

- 记录上一轮最高使用率的战术标签，如护盾、突袭、控制、灼烧；
- Boss 获得一项轻度适应；
- 玩家同时获得一条可靠反制情报；
- 适应不能完全免疫该流派；
- 同一 Boss 最多激活两项适应，防止长期叠加无解。

## 23. 剧情与章节结构

### 23.1 六篇 48 章

| 篇章 | 章节 | 主题 | 系统职责 |
|---|---|---|---|
| 灾变初临 | 1～8 | 生存与组队 | 教学五人编队、资源探索、首个 Boss |
| 秩序崩塌 | 9～16 | 人类势力 | 交涉、阵营、PVE 人类职业队 |
| 异变生态 | 17～24 | 世界生态 | 属性弱点、环境压力、异能代价 |
| 极光计划 | 25～32 | 人造实验体 | 每个 Boss 检验一种阵容能力 |
| 裂隙时代 | 33～40 | 维度融合 | 站位扭曲、裂隙构式、世界锚点 |
| 终焉轮回 | 41～48 | 真相与选择 | 轮回因果、复制构筑、多结局 |

### 23.2 第一篇重排

| 章节 | 内容 | 主要教学 |
|---|---|---|
| 第1章 黑雨 | 陈末苏醒，单人逃离地下室，结尾遇见林美 | 普攻、技能、探索与撤离 |
| 第2章 封锁线 | 林美正式入队 | 前后排、灵能控制 |
| 第3章 最后的超市 | 陈锋加入 | 守卫、资源搜索、噪音 |
| 第4章 夜行者 | 苏晓加入 | 标记、远程与属性弱点 |
| 第5章 临时营地 | 老周加入，首次完整五人队 | 五人阵型、自动策略 |
| 第6章 地铁深处 | 小七加入，首次需要替补选择 | 治疗、换人、伤势 |
| 第7章 疫变区 | 主角异能觉醒 | 构式、污染、症状 |
| 第8章 血色医院 | 缝合感染体 Boss | 综合检验 |

林美可在第1章出现，但第2章才成为可操作伙伴，以消除“登场”和“正式加入”的叙事冲突。

### 23.3 剧情选择原则

- 选择应改变资源、关系、情报、路线或世界状态；
- 不使用大量无后果对白选项；
- 属性和职业提供额外方案，但不保证永远是最优答案；
- 关键选择在轮回后出现新解释；
- 多结局由多条长期变量组合，而非最后一个按钮决定。

## 24. 装备、成长与经济

### 24.1 装备槽

```text
武器：决定射程、攻击属性、基础技能修正
防具：决定生存、位置适配、抗性
饰品：提供战术条件、能量、状态或探索能力
```

### 24.2 装备词条

每件装备：

- 1 个主属性；
- 1 个固定战术特性；
- 0～2 个副词条；
- 高品质增加特性深度，不仅提高数值。

示例：

**折叠防暴盾**

- DEF +18；
- 前排时护盾强度 +12%；
- 首次拦截后使攻击者破势 +15；
- 不给后排角色提供同等收益。

### 24.3 套装与构筑

不做 6 件套。采用轻量两件组合：

| 套装 | 两件效果 |
|---|---|
| 守望 | 护卫后获得少量护盾 |
| 猎手 | 攻击标记目标时命中与暴击提高 |
| 过载 | 对护盾目标伤害与削能提高 |
| 腐解 | 施加腐蚀时有概率延长一回合 |
| 共感 | 净化队友时自身获得能量 |

### 24.4 资源层级

| 类型 | 资源 | 用途 |
|---|---|---|
| 本轮生存 | 口粮、水、药品 | 探索与恢复 |
| 本轮制作 | 废料、电子件、生体样本 | 装备、道具、设施 |
| 本轮战斗 | 晶核 | 技能临时升级、构式强化 |
| 永久成长 | 记忆碎片 | 记忆阶级、模块解锁 |
| 轮回选择 | 轮回印记 | 记忆槽、遗产槽、世界锚点 |
| 叙事资源 | 情报、遗物 | 路线、Boss、结局 |

### 24.5 伙伴获取

建议取消付费角色抽卡冲突：

- 主线伙伴固定加入；
- 支线伙伴通过事件和条件招募；
- 隐藏伙伴通过轮回线索和特殊结局解锁；
- “补给券”仅用于抽取本轮物资或装备，不抽独占伙伴；
- 已解锁伙伴永久保留，但本轮等级和装备重置。

### 24.6 商业模式建议

优先选择：

```text
免费试玩首篇 + 一次性解锁完整版
可选去广告
仅售外观、营地装饰和配乐包
```

禁止：

- 出售战斗数值；
- 出售体力或行动次数；
- 付费专属伙伴；
- 付费概率提升；
- 以失败为前提售卖复活。

## 26. 战斗 UI 与交互

### 26.1 竖屏战斗布局

```text
顶部：敌方头像、职业、弱点、Boss 阶段
上半区：敌方 3×3 阵型与技能预警
中部：行动顺序、战斗日志、状态提示
下半区：我方 3×3 阵型、血量、能量、关键状态
底部：普通攻击 / 技能一 / 技能二 / 觉醒技 / 目标切换
边角：自动、速度、暂停、设置
```

### 26.2 信息优先级

必须常驻：

- 当前行动者；
- 技能冷却；
- 觉醒能量；
- 生命与护盾；
- 标记、护卫、控制、蓄力；
- 属性弱点；
- 可被拦截和将要命中的目标线。

折叠显示：

- 完整数值；
- 状态说明；
- 伤害计算；
- 战斗日志详情。

### 26.3 战前编队界面

应提供：

- 敌方阵型预览；
- 敌方职业和属性图标；
- 我方五格拖拽部署；
- 保护关系连线；
- 队伍缺口提示；
- 连携预览；
- 自动策略模板；
- 一键推荐只能给出原因，不自动覆盖玩家配置。

示例提示：

```text
警告：敌方拥有两名突袭单位，后右的苏晓仅受一名前排保护。
建议：将陈锋置于前右，或为苏晓装备警戒模块。
```

### 26.4 战斗反馈

- 物理/动能伤害：暖白或红；
- 灵能伤害：蓝紫；
- 弱点：破裂图标与“弱点”文字；
- 拦截：明确连线与前排踏步；
- 破势：稳定条碎裂；
- 终结：短暂停顿，不超过 0.35 秒；
- 自动模式仍需展示关键连携名称。

### 26.5 可访问性

- 属性不能只用颜色区分，必须配图标与文字；
- 动效强度可调；
- 战斗速度 1×/2×/3×；
- 支持暂停查看技能；
- 字体最小尺寸和点击区遵循移动端规范；
- 自动战斗失败后可查看“主要失败原因”。

#### Gate 4：轮回闭环

内容：

- 一次死亡或主动轮回；
- 记忆、遗产、世界锚点；
- 快速路线；

- 死亡到新轮开始小于 5 秒；

## 30. 平衡目标与数据指标

### 30.1 阵容平衡

- 单一角色全模式使用率长期不超过 75%；
- 单一成熟阵容在同练度关卡中的最优占比不超过 40%；
- 主坦、主 C、治疗不应只有唯一人选；
- 无治疗队、单坦队、双突袭队可以成立，但应有清晰风险；
- 每个 Boss 至少支持三种机制解法。

### 30.2 战斗可读性

- 新玩家第 3 场战斗前能说清前排保护后排；
- 第 8 章前能识别标记、破甲、治疗和控制的作用；
- 失败报告中 70% 以上玩家认可系统给出的主要失败原因；
- 半自动和手动在同阵容下的胜率差距目标为 5%～15%，体现操作价值但不惩罚自动玩家。

### 30.3 数值边界

| 项目 | 建议边界 |
|---|---|
| 闪避 | 常态不超过 35%，极限短时不超过 60% |
| 最终减伤 | 上限 75% |
| 单体护盾 | 不超过目标最大生命 40% |
| 总护盾 | 不超过目标最大生命 60% |
| 单次硬控 | 普通敌人最多 1 回合，Boss 递减 |
| 复苏 | 每场全队最多 1 次 |
| 额外主动行动 | 每角色每回合最多 1 次 |
| 反击/协同 | 每角色每回合各最多 2 次 |
| 弱点倍率 | 1.25 |
| 抗性倍率 | 0.80 |

### 30.4 迭代方法

1. 先用无装备、同等级角色进行职业模板模拟；
2. 再加入技能模块；
3. 再加入装备和异能；
4. 分别统计普通战、精英战、Boss 战；
5. 平衡优先调整机制条件、冷却和目标规则，最后才调整基础属性；
6. 禁止通过单纯提高敌人 HP 修复所有难度问题。

## 31. 功能规格模板

今后任何技能、敌人、探索点和系统，不得只写一句概念。必须包含：


## 32. 必须锁定的设计决策

以下内容作为 V6.2 基线，不应在实现中被随意改回：

1. 五人静态阵型回合制，不改成自由移动战棋。
2. 默认 2 前排 + 3 后排，3×3 作为阵型容器。
3. 职业克制通过机制，属性克制使用 1.25 / 0.80 的软倍率。
4. 常规技能主要用冷却，觉醒技主要用能量。
5. 异能通过构式修改职业技能，不增加第二套庞大操作栏。
6. 医疗、护卫、突袭、标记、削能等职业权限必须保持边界。
7. 资源地图发现出口后可随时撤离，不强制清图。
8. Boss 高威胁技能必须有预警和多种反制。
9. 轮回使用有限记忆、遗产和世界锚点，而非无限累积。
10. 伙伴通过剧情和事件获取，不售卖概率独占战斗角色。
11. 首个垂直切片必须包含真实五人队，不再以三名角色代表完整战斗。
12. 所有数值进入开发前都需配置化，禁止散落硬编码。

## 34. 市场研究提炼

本方案不是照搬单一产品，而是抽取适合本项目的设计结构：

- 《最强祖师》玩家阵容实践中常用“主 C、副 C、主 T、副 T、功能位”解释五人队，说明五人队的价值来自清晰职责和替补关系，而不是五个最高战力角色简单叠加。
- 《Etrian Odyssey》系列通过前后排、近战射程和远程/魔法例外规则，让位置直接改变可攻击目标与伤害效率。
- 《Darkest Dungeon》系列将技能可用位置与目标位置绑定，使角色被打乱站位后需要不同应对。
- 《Unicorn Overlord》允许玩家提前配置技能的使用条件，证明“自动战斗仍可承载战前策略”。
- 《Dislyte》等五人回合制游戏用属性优势强化选人，但属性倍率应保持为软克制，避免完全替代职业和技能判断。
- 《Hades》的组合祝福说明局内构筑最有价值的部分不是单个强化，而是不同能力之间产生新的组合结果。
- 《Slay the Spire》强调角色、卡牌、遗物共同形成构筑身份，启发本作使用有限模块和构式槽，而不是让所有强化无限叠加。

## 35. 最终总结

《异变纪元：幸存者编队》的战斗核心应明确为：

> **五人职业编队 × 前后排保护关系 × 战前技能与自动策略 × 铺垫—增幅—终结连携 × 职业机制反制 × 属性弱点 × 异能构式。**

玩家最重要的问题不是“这回合往哪里走”，而是：

- 面对这支敌方队伍该带谁；
- 主坦站在哪一侧；
- 主 C 是否获得足够保护；
- 该用标记处决、灵能引爆、护卫反击还是快攻突袭；
- 敌方有治疗、护盾、控制或突袭时，自己缺哪种反制；
- 当前轮回的主角属性和异能源核适合补哪个职业；
- 继续深入是否值得承担伤势、负重与污染；
- 本轮结束时应保留哪一条记忆和哪一件遗产。

只要这条主轴保持清晰，伙伴、装备、异能、探索和轮回都会服务于同一个可理解的构筑目标，而不会再次变成彼此独立的功能清单。
