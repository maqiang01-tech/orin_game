# 第三优先级：集中修 Router V1.1.0

不要现在同时做 V1.1.1、V1.1.2、V1.2。

先修这 **6+1 项**。

## P1-1 Cache 读取重新验证

现在不能：

```text

→ 直接返回 Analysis
```

必须：

```text

↓
重新计算 Artifact Hash
↓

↓

↓

↓

```

否则：

```text
CACHE_ARTIFACT_INTEGRITY_FAILED
```

## P1-2 扩大 Analysis Signature

现在 Cache Key 必须覆盖需求语义中真正会影响分析结果的内容。

至少：

```text
normalized_requirement_hash
scope_hash
constraints_hash
required_capabilities_hash
quality_requirement_hash
acceptance_hash
spec_hash
workflow_hash
policy_hash
skill_hash
baseline_hash
analysis_policy_hash
```

尤其：

```text
能力要求改变
范围改变
质量要求改变
验收标准改变
```

必须导致 Cache Miss。

---

## P1-3 Shadow Route 必须继承 Hard Constraints

这是高优先级。

不能：

```text
正式 Router:
C-WF L3 → Astra

Shadow Route:
C-WF L3 → Sol
```

Requirement Intelligence 只能**增加要求**，不能降低已有硬门槛。

最终计算应类似：

```text
effective_floor =
max(
    hard_route_floor,
    role_mode_floor,
    risk_floor,
    capability_floor,
    requirement_analysis_floor,
    memory_floor
)
```

## P1-4 Capability Matching 改成严格 Registry

不要：

```text
deep_code
≈ code
≈ coding
≈ software
```

自动放宽。

正确：


否则：

```text
UNKNOWN_CAPABILITY
```

必须 fail-closed。
